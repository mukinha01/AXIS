# Decisões

## D001 — Página estática sem framework · 2026-09-16

O escopo é uma página com três opções. HTML, CSS e JavaScript atendem sem instalação ou build. React e a stack do ECHO não são necessários. Organização documental foi reaproveitada, tecnologia foi dimensionada para este produto.

## D002 — Profundidade com imagens · 2026-09-16

Fotografias recortadas, perspectiva CSS e sombras entregam o efeito acordado com menor complexidade que modelos 3D. Não existe giro de 360 graus.

## D003 — Informações fictícias · 2026-09-16

Marca, endereço, preços e horários são demonstração. A página declara o caráter fictício no rodapé.
