# Protocolo AXIS

Leia antes de editar: segunda-mente/AXIS/AXIS.md e as notas Visao, Arquitetura, Regras-visuais, Mapa-do-projeto, Decisoes, Estado-atual e Proxima-tarefa apontadas pelo índice.

A direção atual substituiu a cafeteria por pedido do usuário. As notas em segunda-mente/Cafe são histórico.

- Preserve a experiência AXIS: uma página, 3D, motion em contexto de UX e temas claro e escuro. Sem banco ou backend.
- Execute o escopo autorizado pelo usuário; não aumente produto para preencher um template.
- Mantenha teclado, toque, foco, rolagem nativa e movimento reduzido.
- Não copie identidade, assets ou código do site de Lando Norris. A referência é de ritmo e interação.
- Só adicione dependências quando houver necessidade concreta. Three.js é fixado e servido localmente.
- Confira desktop e mobile, ambos os temas e interações alteradas. No laboratório, confira categoria, dica, persistência e desfazer. Execute npm test ao alterar motor de ideias.
- Antes de encerrar, execute npm run check e atualize mapa, estado, próxima tarefa, diário e decisões quando aplicável. Declare apenas verificações reais.
- Não delegue para agentes sem pedido explícito do usuário.

npm ci prepara vendor; npm run dev abre o servidor; npm run check valida sintaxe, documentos, links e assets.
